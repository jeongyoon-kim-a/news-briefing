사용법
  • 국내·국제 검색창은 독립적으로 동작합니다.
  • 각 검색창에 검색어를 입력하고 매체 버튼을 누르면 새 탭에서 검색 결과가 열립니다.
  • Enter를 누르거나 "전체 열기"를 클릭하면 모든 매체에서의 검색 결과가 한 번에 열립니다.
  • 자주 쓰는 검색어(Saved searches)의 버튼을 클릭하면 간편하게 검색창에 검색어를 입력할 수 있습니다.
  • 검색어 없이 매체 버튼 클릭 시 매체의 메인 화면이 열립니다.
  • 대부분의 매체는 최신 순 정렬을 기본으로 적용했습니다. (Bloomberg는 자체 정렬 기준 적용)
  • 구독이 필요한 매체의 경우 해당 브라우저에 로그인 정보가 저장되어 있다면 문제 없이 사용할 수 있습니다.
  • 처음 사용 시 브라우저가 여러 탭 열기를 팝업으로 차단할 수 있으니, 이 사이트의 팝업을 허용해 주세요.
